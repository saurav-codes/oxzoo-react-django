# oxzoo-react-django

Deployed with [ox](https://deploywithox.com): deploy a repo to your own server with one command, no Docker. [Docs](https://deploywithox.com/docs) · [Guide for this stack](https://deploywithox.com/docs/guides/django)

An [ox](https://deploywithox.com) deploy example: a Django 5.2 API on gunicorn, installed with uv, with a React SPA built by Vite, deployed to your own Ubuntu server. systemd runs gunicorn, and Caddy serves the built SPA with an `index.html` fallback while sending only `/api` and `/health` to Django.

## Stack

| Layer | Tool | Role |
|---|---|---|
| Frontend | React + Vite | SPA built to `dist/` from `client/` |
| API | Django 5.2 on gunicorn 23 | `GET /api/greeting` and `GET /health`; no models, no database |
| Python | 3.13 (`.python-version`), uv | `uv.lock` is committed |
| Node | 24 | `package-lock.json` is committed |

## ox.toml

```toml
# Django API on gunicorn (uv) + React SPA (npm) in one repo.

[app]
start  = "uv run gunicorn hello.wsgi:application --bind 127.0.0.1:$PORT --workers 2"
health = "/health"

[static]
dir = "dist"
spa = true
api = ["/api", "/health"]

[build]
commands = ["uv sync --frozen --no-dev", "npm run build"]

[tools]
node = "24"
```

The repo has two languages, so `[build] commands` names both: `npm ci` is detected from `package-lock.json` and runs first, then the uv sync and the SPA build.

## Environment flow

- **Run time (API):** `hello/views.py` reads `GREETING_TAG` on every `GET /api/greeting`.
- **Build time (SPA):** `vite.config.js` sets `envPrefix: ["GREETING_", "VITE_"]`, so `client/src/App.jsx` reads `import.meta.env.GREETING_TAG` and Vite bakes it into `dist/`. ox sets your variables before the build, and changing one with `ox vars set` redeploys, which rebuilds the SPA.
- **`DJANGO_SECRET_KEY`:** generated by ox on the first review.
- **`ALLOWED_HOSTS`:** `hello/settings.py` uses `PUBLIC_HOST`, which ox provides, plus `127.0.0.1` and `localhost`.

## Deploy with ox

```sh
curl -fsSL https://deploywithox.com/install.sh | sh
ox login
ox new https://github.com/saurav-codes/oxzoo-react-django
printf 'GREETING_TAG=demo\n' | ox review oxzoo-react-django --from-file - --generate DJANGO_SECRET_KEY --wait
```
